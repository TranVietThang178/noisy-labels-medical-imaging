# Impact of Label Noise on Diagnostic Model Reliability in Chest X-ray Classification

MSc in Data Science Dissertation, Atlantic Technological University, 2026.

## Overview

This project investigates how label noise affects the reliability of deep learning models trained for multi-label chest X-ray classification, and whether common noise mitigation methods can restore performance. Using the CheXpert dataset with DenseNet-121, the study evaluates reliability across three dimensions: discrimination (AUC), clinical sensitivity (F2-score), and probability calibration (ECE).

## Key Findings

- DenseNet-121 with ImageNet pretraining is inherently robust to moderate label noise (up to 10%), with AUC dropping only 1.1 percentage points at 10% symmetric noise
- At 40% symmetric noise, AUC degrades by 5.6pp and calibration degrades 13x (ECE from 0.019 to 0.251)
- Most mitigation methods (label smoothing, co-teaching, confident learning) do not improve accuracy and can hurt performance
- MixUp provides modest improvement only under asymmetric noise conditions
- Confident Learning uniquely improves calibration by 47% despite not improving accuracy
- Temperature scaling does not improve calibration in this multi-label setting, likely due to small validation set size (n=202)

## Dataset

This study uses **CheXpert-v1.0-small**, a publicly available chest X-ray dataset
from Stanford ML Group containing 224,316 chest radiographs from 65,240 patients.

Original paper and project page: https://stanfordmlgroup.github.io/competitions/chexpert/

To obtain the data:

1. Download CheXpert-v1.0-small from Kaggle: https://www.kaggle.com/datasets/ashery/chexpert
2. Extract to `data/raw/` so that image paths resolve to `data/raw/CheXpert-v1.0-small/train/...`
3. Download the official test set ground truth labels from: https://github.com/rajpurkarlab/cheXpert-test-set-labels
4. Place the test set images and labels in `data/test/`

After extraction, the data directory should look like:

```
data/
|-- raw/
|   |-- CheXpert-v1.0-small/
|       |-- train/
|       |-- valid/
|       |-- train.csv
|       |-- valid.csv
|-- test/
|   |-- (test images and ground truth labels)
|-- processed/
    |-- (generated by notebook 01)
```

The dataset is not included in this repository due to licensing and size constraints.
The study uses only **frontal-view** X-rays (191,027 training images) and focuses on
five pathologies: Cardiomegaly, Edema, Consolidation, Atelectasis, and Pleural Effusion.

## How to Run

The notebooks are numbered 00 through 08 and should be run in order. Each notebook is self-contained and can be run independently once its prerequisites exist on disk.

### Step 1: Data Exploration (notebook 00)

```
Open: notebooks/00_data.ipynb
Time: ~5 minutes
Requires: CheXpert dataset in data/raw/
Produces: EDA figures and dataset statistics
```

Run all cells. This notebook loads the raw CheXpert CSV files and produces exploratory visualisations including class distributions, sample X-ray images, and a pathology co-occurrence matrix.

### Step 2: Preprocessing (notebook 01)

```
Open: notebooks/01_preprocessing.ipynb
Time: ~10 minutes
Requires: CheXpert dataset in data/raw/
Produces: data/processed/ directory with all train/val/test CSVs and noise-injected CSVs
```

Run all cells. This notebook:
- Filters training data to frontal-view X-rays only (191,027 images)
- Applies U-Ones uncertainty mapping (uncertain labels treated as positive)
- Creates the official validation (202 studies) and test (518 studies) CSVs
- Generates noise-injected training CSVs for all 8 experimental conditions (2 noise types x 4 rates) across 3 seeds

**All subsequent notebooks depend on the CSVs generated here.**

### Step 3: Baseline Training (notebook 02)

```
Open: notebooks/02_baseline_training.ipynb
Time: ~90 minutes (GPU)
Requires: data/processed/ from step 2
Produces: models/baseline_clean_best.pt, results/baseline_clean_test_results.json
```

Run all cells. Trains a DenseNet-121 model on clean (unmodified) labels for up to 5 epochs with early stopping based on validation AUC. The best checkpoint is saved and evaluated on the official test set.

Hyperparameters:
- Architecture: DenseNet-121, ImageNet-pretrained
- Optimiser: AdamW, learning rate 1e-4, weight decay 1e-5
- Loss: Binary cross-entropy with logits
- Batch size: 32
- Image size: 224x224
- Mixed precision training (fp16)

### Step 4: Noise Experiments (notebook 03)

```
Open: notebooks/03_noise_experiments.ipynb
Time: ~36 hours (GPU)
Requires: data/processed/ from step 2
Produces: 24 model checkpoints in models/noise_experiments/,
          24 result JSONs in results/noise_experiments/
```

Run all cells. Trains one model per noise condition per seed using the same hyperparameters as the baseline. The experiment queue is built automatically and skips any experiments that already have a saved result JSON, so the notebook can be safely interrupted and resumed.

Experimental conditions:
- Noise types: symmetric, asymmetric
- Noise rates: 5%, 10%, 20%, 40%
- Seeds: 132, 456, 789
- Total: 2 x 4 x 3 = 24 experiments

Asymmetric noise swaps labels between clinically confusable pathology pairs:
- Consolidation and Atelectasis
- Edema and Pleural Effusion

### Step 5: Noise Analysis (notebook 04)

```
Open: notebooks/04_noise_analysis.ipynb
Time: ~2 minutes (no GPU needed)
Requires: results/noise_experiments/ from step 4
Produces: Publication figures and LaTeX tables in results/figures/
```

Run all cells. Generates AUC degradation curves, per-pathology breakdowns, summary statistics, and LaTeX tables for the dissertation.

### Step 6: Mitigation Experiments (notebook 05)

```
Open: notebooks/05_mitigation_experiments.ipynb
Time: ~72 hours (GPU), varies by method
Requires: data/processed/ from step 2, trained noise models are NOT required
Produces: 48 model checkpoints in models/mitigation_experiments/,
          48 result JSONs in results/mitigation_experiments/
```

Run all cells. Tests four noise mitigation methods under the 20% and 40% noise conditions (both symmetric and asymmetric). Like notebook 03, the experiment queue supports safe resume.

Methods and their key parameters:
- **Label Smoothing** (alpha=0.1): replaces hard 0/1 labels with smoothed values
- **MixUp** (alpha=0.4): interpolates pairs of training images and their labels
- **Co-teaching**: two networks select clean samples for each other based on loss ranking. Forget rate matches the noise rate. Requires batch size 16 due to VRAM constraints (two networks loaded simultaneously)
- **Confident Learning** (via cleanlab library): identifies and removes likely mislabelled samples before training on the cleaned subset

Conditions: 4 methods x 2 noise types x 2 noise rates x 3 seeds = 48 experiments.

Two additional exploratory co-teaching experiments at 5% symmetric noise were run during initial timing analysis but are excluded from the main results.

### Step 7: Mitigation Analysis (notebook 06)

```
Open: notebooks/06_mitigation_analysis.ipynb
Time: ~2 minutes (no GPU needed)
Requires: results/noise_experiments/ and results/mitigation_experiments/
Produces: Comparison charts, improvement heatmap, significance tests, LaTeX tables
```

Run all cells. Compares each mitigation method against the no-mitigation baseline for each noise condition. Includes paired t-tests for statistical significance.

The exploratory co-teaching experiments at 5% noise are filtered out in the first code cell.

### Step 8: Calibration Analysis (notebook 07)

```
Open: notebooks/07_calibration.ipynb
Time: ~15 minutes (GPU)
Requires: Model checkpoints from steps 3, 4, and 6
Produces: results/calibration/ (ECE results, reliability diagrams)
```

Run all cells. Evaluates calibration (Expected Calibration Error) and applies temperature scaling for a representative subset of 7 models: the clean baseline, symmetric noise at 10% and 40%, and all four mitigation methods at 40% symmetric noise.

Temperature scaling learns a single scalar parameter on the validation set (n=202) by minimising binary cross-entropy, then applies it to test set logits before the sigmoid function.

### Step 9: Secondary Metrics (notebook 08)

```
Open: notebooks/08_secondary_metrics.ipynb
Time: ~150 minutes (GPU)
Requires: All model checkpoints from steps 3, 4, and 6
Produces: results/secondary_metrics/ (F2, sensitivity, specificity CSVs and figures)
```

Run all cells. Computes F1, F2, sensitivity, specificity, and precision for every trained model by running inference on the test set. Reports metrics at two decision thresholds:

1. **Default threshold (0.5)**: the standard threshold, which underestimates model quality on imbalanced multi-label data
2. **Optimised threshold**: per-pathology thresholds learned on the validation set by maximising F2-score, then applied to the test set

The threshold optimisation sweeps 91 candidate values from 0.05 to 0.95 per pathology. F2 is chosen for optimisation because it weights recall (sensitivity) twice as heavily as precision, aligning with clinical screening priorities where missing a pathology is more costly than a false positive.

This notebook updates the existing result JSON files from steps 3-6 with a `test_secondary_metrics` key containing both threshold configurations. It is resume-safe and skips models that have already been processed.

## Reproducibility

All experiments use fixed random seeds (132, 456, 789) for PyTorch, NumPy, and CUDA operations. Deterministic behaviour is enabled where supported.

Results can be verified from the saved JSON files in the results/ directory without retraining. The analysis notebooks (04, 06, 07, 08) read from these JSON files and can be re-run at any time.

## Code Organisation

Utility functions (dataset loading, model construction, evaluation) are defined within each notebook rather than in shared modules. This ensures each notebook is self-contained and can be run independently without import dependencies beyond the packages in requirements.txt. The trade-off is some code duplication across the training and analysis notebooks.
